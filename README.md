# Playable desktop downloads

Make and test 3D games in a local studio with Codex or Claude, Blender 4.5 LTS and Godot 4.6.

[Visit the website](https://playable-website.vercel.app) · [Release notes and checksums](https://github.com/gracelungu/playable-releases/releases/tag/v0.1.5)

## Download v0.1.5

| Mac | Download |
| --- | --- |
| Apple silicon (M1 and later) | [Playable-mac-arm64.zip](https://github.com/gracelungu/playable-releases/releases/download/v0.1.5/Playable-mac-arm64.zip) |
| Intel | [Playable-mac-x64.zip](https://github.com/gracelungu/playable-releases/releases/download/v0.1.5/Playable-mac-x64.zip) |

Unzip the download and move Playable.app to Applications. Find your Mac's chip in Apple menu → About This Mac.

These are unsigned, unnotarized early-access builds. AI accounts and usage are separate. Windows and Linux installers are not available yet.

Verify downloads with [SHA256SUMS.txt](https://github.com/gracelungu/playable-releases/releases/download/v0.1.5/SHA256SUMS.txt). Engine licenses, notices and the matching Blender source archive are included in each package.

This repository distributes installers only. Application source is maintained separately.
